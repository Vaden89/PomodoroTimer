# Pomodoro Timer Chrome Extension

A simple and efficient Pomodoro Timer designed primarily for students. This Chrome extension helps you stay focused by breaking your study sessions into manageable intervals with built-in break times.

## Overview

The Pomodoro Timer uses the Pomodoro Technique—a time management method that breaks work into intervals (traditionally 25 minutes of focused work followed by a 5-minute break). This extension is built for Chrome, making it easy to start a session directly from your browser.

## Features

- **Minimalistic Design:** Clean interface for distraction-free time management.
- **Pomodoro Sessions:** Work in 25-minute intervals with 5-minute breaks (both durations are easily configurable).
- **Easy Access:** Launch the timer from your Chrome toolbar.
- **Notifications:** Receive alerts to signal the beginning and end of your work/break periods.
- **Lightweight:** Simple codebase built with HTML, CSS, and JavaScript.

## Installation

To install the Pomodoro Timer as a Chrome extension:

1. **Clone or Download the Repository:**

   ```bash
   git clone https://github.com/Vaden89/PomodoroTimer.git
   ```

2. **Open Chrome Extensions Page:**

   - Navigate to `chrome://extensions/` in your Chrome browser.

3. **Enable Developer Mode:**

   - Toggle the **Developer mode** switch in the top-right corner of the extensions page.

4. **Load the Unpacked Extension:**

   - Click on **Load unpacked** and select the folder where you cloned/downloaded the repository.

5. **Start Using the Timer:**

   - The Pomodoro Timer will now appear as an extension in your Chrome toolbar.

## Usage

1. **Launch the Extension:**

   - Click the extension icon to open the timer interface.

2. **Begin a Pomodoro Session:**

   - Click **Start** to initiate a 25-minute work session.

3. **Take a Break:**

   - When the timer signals the end of your work session, use the break period (default 5 minutes) before starting the next session.

4. **Customize Settings:**
   - Adjust timer durations as needed by editing the code or settings (if a settings interface is implemented in future updates).
